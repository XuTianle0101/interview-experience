# AMD面经合集

> AMD 面试经验整理，涵盖 GPU、AI、软件等方向。

## 面试流程概述

1. **简历投递** — 通过官网或内推
2. **技术一面**（45-60分钟）— 基础 + 编程
3. **技术二面**（45-60分钟）— 项目深挖
4. **Manager 面**（30-45分钟）
5. **HR面**

## 高频考点

### GPU / 图形
- GPU 架构（RDNA / CDNA）

- GPU 驱动开发
- C/C++ 编程

### AI / 加速
- ROCm 生态
- 模型量化 / 部署
- 推理引擎优化
- C++ / Python

### 软件开发
- C++ / Python 基础
- 操作系统 + 编译原理
- 性能优化 / profiling

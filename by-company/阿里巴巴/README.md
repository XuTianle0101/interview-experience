### 样例面经：Java后端实习一面

**基本信息**
- 公司：阿里巴巴
- 岗位：Java 后端开发实习
- 轮次：技术一面
- 形式：电话面 + 在线编程
- 时长：约 65 分钟

**面试流程**

1. 自我介绍 + 聊项目（15分钟）
2. Java 基础问答（25分钟）
3. 数据库 + 中间件（10分钟）
4. 编程题（15分钟）

**技术问题**

1. **Q：HashMap 的底层实现原理？JDK1.8 做了什么优化？**
   - A：数组 + 链表/红黑树。1.8 引入红黑树，链表长度超过 8 且数组长度 ≥ 64 时转红黑树，查找从 O(n) 优化到 O(log n)。

2. **Q：ConcurrentHashMap 怎么保证线程安全？**
   - A：1.8 用 CAS + synchronized 锁住链表头节点，粒度比 1.7 的分段锁更细。put 时先 CAS 插入空节点，失败则 synchronized 锁住头节点。

3. **Q：JVM 的垃圾回收算法有哪些？G1 和 CMS 的区别？**
   - A：标记-清除、标记-整理、复制算法。CMS 是老年代收集器，用标记-清除，有浮动垃圾；G1 是全堆收集器，用标记-整理 + 复制，可预测停顿。

4. **Q：讲讲 Spring AOP 的实现原理？**
   - A：基于动态代理。接口用 JDK 动态代理，类用 CGLIB 字节码增强。AOP 通过 BeanPostProcessor 在 Bean 初始化后创建代理对象。

**编程题**

- 题目：层序遍历二叉树，按层输出
- 思路：BFS，用队列，每层记录当前层节点数。
- 复杂度：时间 O(n)，空间 O(n)。

**经验总结**

- 阿里面试深度很高，Java 基础一定要扎实
- 项目经历会被追问到底层实现，不能只停留在使用层面
- HR 面会考察价值观，提前了解阿里价值观体系
- 建议准备至少一个有深度的项目

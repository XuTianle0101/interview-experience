## 面试流程概述

京东校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **笔试**（可选）— 部分岗位需要
3. **技术一面**（45-60分钟）— 基础 + 编程题
4. **技术二面**（45-60分钟）— 项目 + 系统设计
5. **HR面**（20-30分钟）

## 面试流程概述

快手校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 基础 + 编程题
3. **技术二面**（45-60分钟）— 项目 + 系统设计
4. **技术三面**（30-45分钟）— 综合面
5. **HR面**（20-30分钟）

## 高频考点

### 算法岗位
- 推荐系统（召回、排序、多目标）
- 短视频内容理解
- 计算机视觉 / 多模态
- 手撕代码：数据结构、动态规划

### 开发岗位
- Go / C++ 基础
- 高并发系统设计
- 视频处理与流媒体
- 数据库 + 缓存

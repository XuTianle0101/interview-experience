## 面试流程概述

宇宙厂校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **技术一面**（45-60分钟）— 项目深挖 + 技术八股 + 编程题
3. **技术二面**（45-60分钟）— 系统设计 / 深度技术 + 编程题
4. **技术三面**（30-45分钟）— 综合素质 + 部门负责人面试
5. **HR面**（20-30分钟）— 行为面 + 薪资沟通

- 机器学习基础（过拟合、正则化、梯度下降变体）

- NLP / 推荐 / CV 方向知识

### 样例面经：算法工程师实习一面

**基本信息**
- 公司：宇宙厂
- 岗位：算法工程师（NLP方向）实习
- 轮次：技术一面
- 形式：视频面（飞书）
- 时长：约 55 分钟

**面试流程**

1. 自我介绍（3分钟）
2. 简历项目深挖（15分钟）
3. 技术问答（20分钟）
4. 编程题（15分钟）
5. 反问（2分钟）

**技术问题**

1. **Q：介绍一下 Transformer 的整体结构，Encoder 和 Decoder 有什么区别？**
   - A：Encoder 是双向自注意力，Decoder 用了 masked self-attention 防止看到未来信息，加上 cross-attention 关注 Encoder 输出。

2. **Q：为什么 Transformer 用 LayerNorm 而不是 BatchNorm？**
   - A：NLP 序列长度可变，BatchNorm 对 batch 维度归一化受 padding 影响；LayerNorm 在特征维度归一化，更适合变长序列。

3. **Q：Bert 和 GPT 的预训练任务有什么区别？**
   - A：Bert 用 Masked Language Model（双向），GPT 用自回归语言模型（单向）。Bert 适合理解任务，GPT 适合生成任务。

4. **Q：介绍一下你了解的位置编码，为什么需要？**
   - A：Transformer 没有递归结构，需要位置编码注入位置信息。原论文用正弦余弦编码，后续有可学习位置编码、相对位置编码（T5）、RoPE（旋转位置编码）等。

**编程题**

- 题目：给定一个整数数组，找到最长的递增子序列的长度。
- 思路：动态规划 O(n²) 或 patience sorting O(n log n)。
- 复杂度：时间 O(n log n)，空间 O(n)。

**经验总结**

- 项目深挖比较细，一定要对自己的项目了如指掌
- Transformer 相关的八股很高频，建议系统准备
- 编程题难度中等，LeetCode 中等题水平足够
- 面试官比较友好，会引导

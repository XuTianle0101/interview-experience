## 面试流程概述

OpenAI校招/实习面试通常包含以下环节：

1. **Recruiter Screen**（30分钟）— 初步沟通
2. **Technical Screen**（45-60分钟）— coding / research
3. **Virtual Onsite**（4-5轮，每轮45-60分钟）
4. **Team Matching**
5. **Final Review**

## 高频考点

### Engineering
- 系统设计（ML serving、分布式训练）
- 编程（Python / C++，算法与数据结构）
- LLM 基础（训练、推理优化）
- LLM 相关（tokenization、attention、sampling）

### Research
- 深度学习理论（Transformer、扩散模型、RLHF）
- 论文讨论 + Research proposal
- 从论文到代码复现

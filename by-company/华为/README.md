## 面试流程概述

华为校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网投递
2. **机试**（60-90分钟）— 编程题（通常3道）
3. **技术一面**（45-60分钟）— 基础 + 项目
4. **技术二面**（45-60分钟）— 深度技术 + 编程
5. **业务面**（30-45分钟）— 业务主管面
6. **HR面**（20-30分钟）

## 高频考点

### 算法岗位
- 机器学习 + 深度学习基础
- NLP / CV / 语音
- 模型部署与优化（端侧、Atlas）
- 编程：C++ / Python

### 开发岗位
- C/C++ 基础（重点考察）
- 操作系统 + 计算机网络
- 嵌入式 / 底层开发
- 系统设计：分布式、高可用

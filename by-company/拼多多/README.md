# 拼多多面经合集

## 面试流程概述

拼多多校招/实习面试通常包含以下环节：

1. **简历投递** — 通过官网或内推投递
2. **笔试**（60分钟）— 编程题
3. **技术一面**（45-60分钟）— 基础 + 编程
4. **技术二面**（45-60分钟）— 深度项目 + 设计
5. **HR面**（20-30分钟）

## 高频考点

### 算法岗位
- 推荐系统（召回、排序）
- 搜索相关性
- 广告算法 / CTR预估
- 手撕代码：难度偏高

### 开发岗位
- Java / Go 基础
- 高并发系统设计
- 分布式架构
- 数据库优化

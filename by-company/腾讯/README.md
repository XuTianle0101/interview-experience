1. **笔试/简历筛选** — 部分岗位需要笔试

5. **HR面**（20-30分钟）— 行为面 + offer 沟通

### 样例面经：后端开发实习一面

**基本信息**
- 公司：腾讯
- 岗位：后端开发实习
- 轮次：技术一面
- 形式：视频面
- 时长：约 50 分钟

**面试流程**

1. 自我介绍（2分钟）
2. 项目相关提问（10分钟）
3. 基础知识问答（20分钟）
4. 编程题（15分钟）
5. 反问（3分钟）

**技术问题**

1. **Q：讲讲 TCP 三次握手，为什么不是两次？**
   - A：两次握手无法防止历史连接初始化（已失效的连接请求）。三次握手让双方都确认收发能力正常。

2. **Q：四次挥手中 TIME_WAIT 状态为什么需要等待 2MSL？**
   - A：确保最后一个 ACK 能到达对端；防止本次连接的报文影响下一次连接。

3. **Q：MySQL InnoDB 的索引结构是什么？为什么用 B+ 树？**
   - A：B+ 树。相比 B 树，非叶子节点不存数据，扇出更大，树更矮，磁盘 IO 更少；叶子节点用链表连接，范围查询高效。

4. **Q：Redis 的持久化方式有哪些？**
   - A：RDB（快照，全量）和 AOF（日志，增量）。RDB 恢复快但可能丢数据，AOF 更安全但文件大、恢复慢。

**编程题**

- 题目：反转链表（从 m 到 n 的位置反转）
- 思路：定位到 m 位置，逐个反转到 n 位置，连接头尾。
- 复杂度：时间 O(n)，空间 O(1)。

**经验总结**

- 腾讯注重基础功底，计算机网络和操作系统是重点
- C++ 岗位会问比较多语言特性
- 编程题偏基础，但要注意边界条件
- 建议提前在牛客网刷腾讯真题
